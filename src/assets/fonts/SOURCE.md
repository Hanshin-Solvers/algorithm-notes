# Font sources

## Nanum Gothic

- Source: [Google Fonts — Nanum Gothic](https://github.com/google/fonts/tree/main/ofl/nanumgothic)
- Files: NanumGothic-Regular.ttf, NanumGothic-Bold.ttf
- License: OFL.txt
- WOFF2 files are generated from the TTF originals with FontTools.
- Korean text uses Nanum Gothic, including inline SVG text labels.

## Inter

- Source: [Inter official distribution](https://rsms.me/inter/)
- File: [InterVariable.woff2, version 4.1](https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1)
- License: Inter-OFL.txt, SIL Open Font License 1.1
- The original variable WOFF2 is served locally with weight and optical-size axes.
- Latin letters, digits, and basic punctuation use Inter. The CSS Unicode range keeps Korean text in Nanum Gothic.
