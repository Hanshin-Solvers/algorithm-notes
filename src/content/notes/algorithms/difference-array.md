## 개념

인접한 값의 차이를 저장하는 배열입니다. $D_1=A_1$, $D_i=A_i-A_{i-1}$로 정의하면 차분 배열의 누적 합으로 원래 배열을 복원할 수 있습니다.

### 구간에 같은 값 더하기

$l$번째부터 $r$번째까지 $x$를 더하려면 $D_l$에 $x$를 더하고 $D_{r+1}$에서 $x$를 뺍니다. 누적 합을 구할 때 $l$부터 증가량이 적용되고 $r+1$부터 상쇄됩니다.

길이가 $5$인 영 배열에서 $[2,4]$에 $3$을 더하면 경계의 차분만 바뀌고, 복원 결과는 $[0,3,3,3,0]$입니다.

차분을 다시 더하면 $(A_1)+(A_2-A_1)+(A_3-A_2)=A_3$처럼 중간 값이 상쇄됩니다. 이것이 누적 합으로 원래 값을 복원할 수 있는 이유입니다.

구간 전체에 $x$를 더해도 구간 내부의 인접한 두 값의 차이는 $(A_i+x)-(A_{i-1}+x)=A_i-A_{i-1}$로 같습니다. 왼쪽 경계는 앞 원소보다 $x$만큼 더 커지고, 오른쪽 경계 다음은 앞 원소에 비해 $x$만큼 작아지므로 두 경계의 차이만 바뀝니다.

위 예의 차분은 $[0,3,0,0,-3]$입니다. 왼쪽부터 더하면 $0,3,3,3,0$이 되어 구간에만 $3$이 적용됩니다. 마지막 원소까지 갱신한다면 오른쪽 경계 다음 칸은 배열 바깥의 종료 표시로 생각할 수 있습니다.

이 방법은 여러 구간에 값을 더한 뒤 최종 배열을 한 번 구하는 문제에 적합합니다. 매 갱신 직후의 구간 합까지 필요하다면 복원 비용이 반복되므로 세그먼트 트리처럼 갱신과 질의를 함께 처리하는 방법을 검토합니다.

### 복잡도

모든 갱신이 끝난 배열이 필요한 경우에 적합합니다. 원소 수를 $N$, 갱신 수를 $Q$라고 합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 구간 갱신 기록 | $O(1)$ | 추가 $O(1)$ |
| 최종 배열 복원 | $O(N)$ | 차이 배열 $O(N)$ |
| 전체 갱신과 복원 | $O(N+Q)$ | 차이 배열 $O(N)$ |

## 예제

### 문제

처음에 모든 원소가 0인 배열에 구간 덧셈을 수행한 뒤 최종 배열을 구합니다.

### 입력

첫째 줄에 $1\le N,Q\le100$인 $N,Q$가 주어집니다. 다음 $Q$개 줄에 $l,r,x$가 주어집니다. $1\le l\le r\le N$이며 $x$는 $100$ 이하의 자연수입니다.

### 출력

최종 배열의 값을 순서대로 한 줄에 출력합니다.
