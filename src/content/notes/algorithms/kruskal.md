## 개념

### 최소 신장 트리 구성

크루스칼 알고리즘은 무방향 그래프의 간선을 가중치가 작은 순서대로 확인하여 최소 신장 트리를 만듭니다. 모든 정점을 연결하면서 선택한 간선의 가중치 합을 최소로 합니다.

처음에는 각 정점을 별개의 연결 요소로 둡니다. 간선의 양 끝점이 서로 다른 연결 요소에 속하면 간선을 선택하고 두 요소를 합칩니다. 같은 요소에 속하면 해당 간선을 추가할 때 사이클이 생기므로 건너뜁니다. 같은 요소인지 확인하고 합치는 연산에는 DSU를 사용합니다.

정점 수가 $V$일 때 $V-1$개의 간선을 선택하면 신장 트리가 완성됩니다. 그래프가 연결되어 있지 않으면 모든 정점을 연결하는 신장 트리를 만들 수 없습니다.

예를 들어 세 정점 사이의 간선 비용이 $A\! -\! B:2$, $B\! -\! C:2$, $A\! -\! C:3$이면 비용 $2$인 두 간선을 골라 총비용 $4$로 모두 연결합니다. 마지막 비용 $3$인 간선까지 고르면 이미 연결된 정점 사이에 사이클이 생기며 비용만 늘어납니다.

최소 신장 트리는 전체 연결 비용을 최소화합니다. 위 트리에서 $A$에서 $C$까지의 경로 비용은 $4$이지만, 원래 그래프의 직접 간선을 이용한 최단 거리는 $3$입니다. 따라서 한 시작점의 최단 경로 문제와 구분해서 선택합니다.

### 작은 간선을 먼저 선택하는 이유

서로 다른 두 연결 요소를 잇는 간선 중 가장 가벼운 간선을 선택합니다. 어떤 최소 신장 트리가 이 간선을 사용하지 않는다면, 이 간선을 추가해서 생기는 사이클에서 두 요소를 잇는 다른 간선을 제거할 수 있습니다. 새 간선이 더 무겁지 않으므로 최소 비용을 유지할 수 있습니다.

### 복잡도

정점 수를 $V$, 간선 수를 $E$라고 합니다. 경로 압축과 크기 기준 합치기를 적용한 DSU를 사용합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 간선 정렬 | $O(E\log E)$ | 간선 $O(E)$ |
| DSU로 간선 선택 | $O(E\alpha(V))$ | DSU $O(V)$ |

## 예제

### 문제

무방향 그래프의 최소 신장 트리 가중치 합을 구합니다.

### 입력

첫째 줄에 정점 수 $N$과 간선 수 $M$이 주어집니다. 다음 $M$개 줄에 간선의 양 끝점과 가중치가 주어집니다. $1 \le N \le 100$, $0 \le M \le 300$이며 가중치는 $1$부터 $100$까지입니다. 정점 번호는 $1$부터 $N$까지입니다.

### 출력

최소 신장 트리의 가중치 합을 출력합니다. 모든 정점을 연결할 수 없으면 IMPOSSIBLE을 출력합니다.
