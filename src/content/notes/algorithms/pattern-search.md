## 개념

### 시작 위치마다 비교하기

문자열에서 특정 패턴이 등장하는 위치를 찾는 가장 직접적인 방법은 시작 위치를 하나씩 옮기면서 패턴의 문자들을 비교하는 것입니다.

문자열 길이를 $N$, 패턴 길이를 $M$이라고 하면 시작 위치는 $0$부터 $N-M$까지 확인합니다. 각 위치에서 $M$개 문자가 모두 같으면 패턴이 등장합니다. 문자가 다르면 다음 시작 위치로 이동합니다.

`ABABABA`에서 `ABA`는 위치 $0$, $2$, $4$에 등장합니다. 한 번 찾은 뒤에도 시작 위치를 한 칸씩 이동하면 겹치는 패턴도 찾을 수 있습니다.

길이 $7$인 본문에서 길이 $3$인 패턴은 시작 위치 $4$에 놓으면 마지막 위치 $6$까지 차지합니다. 시작 위치가 $5$이면 패턴 끝이 본문 밖으로 나가므로 $N-M=4$까지만 확인합니다. 패턴이 본문보다 길면 들어갈 시작 위치가 없습니다.

이 방법은 짧은 문자열에서 구현 흐름을 확인하기 쉽습니다. 다만 본문이 `AAAAAA`, 패턴이 `AAAB`라면 시작 위치마다 앞의 `AAA`를 다시 비교한 뒤 마지막에서 실패합니다. 이런 반복 비교가 긴 문자열에서 많아지면 KMP처럼 이미 일치한 부분을 재사용하는 방법으로 계산량을 줄일 수 있습니다.

### 복잡도

본문 길이를 $N$, 패턴 길이를 $M$, 찾은 위치 수를 $K$라고 합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 모든 시작 위치 비교 | $O(NM)$ | 결과 $O(K)$, 비교용 추가 $O(1)$ |

## 예제

### 문제

문자열에서 주어진 패턴이 등장하는 모든 시작 위치를 구합니다. 서로 겹치는 등장 위치도 포함합니다.

### 입력

첫째 줄에 문자열, 둘째 줄에 패턴이 주어집니다. 두 문자열은 영어 대문자로 이루어져 있고 길이는 각각 $1$부터 $100$까지입니다.

### 출력

첫째 줄에 등장 횟수를 출력합니다. 둘째 줄에 시작 위치를 작은 순서대로 출력합니다. 위치는 0부터 셉니다. 등장하지 않으면 둘째 줄을 비워 둡니다.
