## 개념

정렬은 비교 기준에 따라 원소의 순서를 정하는 작업입니다. 수의 오름차순, 점수의 내림차순처럼 먼저 와야 할 원소의 조건을 정합니다.

### 기본 정렬과 부분 구간

| 동작 | C++ | Java | Python |
|---|---|---|---|
| 오름차순 | `sort(v.begin(), v.end())` | `Arrays.sort(a)` | `lst.sort()` |
| 내림차순 | `sort(v.begin(), v.end(), greater<int>())` | 객체 배열에 `Comparator.reverseOrder()` | `lst.sort(reverse=True)` |
| 정렬된 복사본 | 복사 후 정렬 | 복사 후 정렬 | `sorted(lst)` |
| 구간 `[l, r)` 정렬 | `sort(v.begin() + l, v.begin() + r)` | `Arrays.sort(a, l, r)` | `lst[l:r] = sorted(lst[l:r])` |

Java의 기본형 배열은 기본 오름차순 정렬을 지원합니다. 사용자 정의 비교가 필요하면 객체 배열이나 리스트를 사용합니다.

### 여러 기준으로 정렬

점수가 다르면 높은 점수가 먼저 오고, 점수가 같으면 번호가 작은 원소가 먼저 오도록 정할 수 있습니다. C++은 비교 함수, Java는 Comparator, Python은 정렬 키를 사용합니다. 구조체·객체·튜플의 여러 필드를 순서대로 비교하는 방식도 같습니다.

비교 함수는 같은 두 원소에 대해 일관된 결과를 내야 합니다. C++에서 같은 값을 비교할 때는 거짓을 반환하고, Java에서는 $0$을 반환합니다. Java의 정수 비교는 `Integer.compare`를 사용하면 뺄셈의 범위 초과를 피할 수 있습니다.

안정 정렬은 비교 기준이 같은 원소의 기존 순서를 보존합니다. C++의 `stable_sort`, Java의 객체 배열 정렬, Python의 정렬은 안정 정렬입니다. 동점 순서를 별도로 정할 때는 비교 기준에 해당 항목을 추가합니다.

예를 들어 `(번호, 점수)`가 $(3,80),(1,90),(2,90)$이면, 점수 내림차순·번호 오름차순의 결과는 $(1,90),(2,90),(3,80)$입니다. 먼저 점수를 비교하고, 점수가 같을 때만 번호를 비교하기 때문입니다.

이 기준을 C++의 비교 함수는 “첫 번째 원소를 앞에 둘 것인가”로 판단합니다. Java의 비교 결과는 첫 번째 원소가 앞이면 음수, 같으면 $0$, 뒤면 양수입니다. Python은 `(-점수, 번호)`와 같은 키를 오름차순으로 비교하면 점수가 큰 순서와 번호가 작은 순서를 함께 표현할 수 있습니다.

안정 정렬과 보조 기준은 결과가 다를 수 있습니다. 점수가 같은 $(2,90),(1,90)$이 이 순서로 입력되었다면, 점수만 비교하는 안정 정렬은 $2$번을 $1$번보다 앞에 둡니다. 번호 오름차순을 보조 기준으로 넣으면 입력 순서와 관계없이 $1$번을 $2$번보다 앞에 둡니다.

### 복잡도

원소 수를 $N$이라고 합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| C++ sort | $O(N\log N)$ | 추가 $O(\log N)$ |
| Java 객체 정렬·Python 정렬 | $O(N\log N)$ | 추가 $O(N)$ |

## 예제

### 문제

참가자를 점수가 높은 순서로 나열합니다. 점수가 같으면 번호가 작은 참가자가 먼저 옵니다.

### 입력

첫째 줄에 참가자 수 $1\le N\le100$이 주어집니다. 다음 $N$개 줄에 번호와 점수가 주어집니다. 번호는 서로 다른 $1$ 이상 $9999$ 이하의 정수이고, 점수는 $1$ 이상 $100$ 이하입니다.

### 출력

정렬된 참가자 번호를 한 줄에 공백으로 구분하여 출력합니다.
