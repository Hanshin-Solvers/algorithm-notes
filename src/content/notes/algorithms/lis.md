## 개념

부분 수열은 원래 순서를 유지하면서 일부 원소를 골라 만든 수열입니다. LIS는 값이 엄격히 증가하는 부분 수열 중 가장 긴 것입니다.

$[3,1,2,5,4]$에는 $[1,2,4]$와 $[1,2,5]$가 있고 LIS의 길이는 $3$입니다. 값이 같은 원소를 이어 붙이면 엄격한 증가가 아닙니다.

### 위치별 DP

$D_i$를 $i$번째 원소로 끝나는 LIS 길이로 정의합니다. 앞쪽의 더 작은 값을 찾고 $D_i=\max(D_i,D_j+1)$로 갱신합니다. 원소 하나만 고르는 초기값은 $1$입니다. 이 방법은 $O(N^2)$ 시간이 걸립니다.

예를 들어 $[3,1,2,5,4]$의 각 위치에서 끝나는 길이는 $[1,1,2,3,3]$입니다. 값 $2$ 앞에는 더 작은 $1$이 있으므로 길이가 $2$이고, 값 $5$에는 길이 $2$인 $[1,2]$를 이어 길이 $3$을 만들 수 있습니다. 이전 원소를 모두 비교하는 이 방법은 원소 수가 작을 때 흐름을 확인하기 쉽습니다.

### 길이별 최소 끝값

같은 길이라면 마지막 값이 작을수록 다음 원소를 붙이기 쉽습니다. 각 길이에 대해 가능한 가장 작은 끝값을 저장합니다. 새 값 이상인 첫 위치를 이분 탐색하여 교체하고, 그런 위치가 없으면 뒤에 추가합니다.

최소 끝값 배열의 길이가 LIS 길이입니다. 이 배열의 원소들은 서로 다른 부분 수열에서 올 수 있으므로 실제 LIS를 복원하려면 이전 원소 위치를 따로 저장합니다.

$[3,1,2,5,4]$를 왼쪽부터 처리한 최소 끝값 목록은 다음과 같습니다.

| 새 원소 | 길이별 최소 끝값 | 변화의 이유 |
| --- | --- | --- |
| $3$ | $[3]$ | 길이 $1$인 수열을 만듦 |
| $1$ | $[1]$ | 같은 길이의 끝값을 더 작게 만듦 |
| $2$ | $[1,2]$ | 끝의 $1$보다 커서 길이 $2$로 연장 |
| $5$ | $[1,2,5]$ | 길이 $3$으로 연장 |
| $4$ | $[1,2,4]$ | 길이 $3$의 끝값을 $5$에서 $4$로 낮춤 |

끝값이 $5$인 수열 뒤에는 $5$보다 큰 수만 붙일 수 있지만, 끝값이 $4$이면 이후의 $5$도 붙일 수 있습니다. 따라서 같은 길이에서는 작은 끝값을 남겨도 앞으로 만들 수 있는 길이를 잃지 않습니다. 새 값과 같은 끝값을 찾았을 때는 교체하므로 같은 값으로 길이가 증가하지 않습니다.

원소가 $1000$개이면 위치별 DP의 비교 수는 대략 $100$만 이하이지만, $100000$개이면 수십억 번으로 늘어납니다. 입력이 커서 모든 이전 위치를 비교하기 어렵다면 이분 탐색을 활용한 방법을 선택합니다.

### 복잡도

원소 수를 $N$이라고 합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 위치별 DP | $O(N^2)$ | DP 표 $O(N)$ |
| 이분 탐색 활용 | $O(N\log N)$ | 최소 끝값 $O(N)$ |

## 예제

### 문제

수열의 최장 증가 부분 수열의 길이를 구합니다.

### 입력

첫째 줄에 $1\le N\le1000$이 주어집니다. 둘째 줄에 10000보다 작은 자연수 $N$개가 주어집니다.

### 출력

LIS의 길이를 출력합니다.
