## 개념

### 정수 자료형

정수를 저장할 때는 입력뿐 아니라 계산 중간에 만들어지는 값의 범위도 확인합니다. 길이가 $N$인 배열의 각 값이 최대 $A$이면 합은 최대 $NA$입니다.

| 항목 | C++ | Java | Python |
| --- | --- | --- | --- |
| 대회에서 흔히 쓰는 기본 정수 | `int` | `int` | `int` |
| 더 큰 정수 | `long long` | `long` | 같은 `int` |
| 정수 최댓값 확인 | `numeric_limits<int>::max()` | `Integer.MAX_VALUE` | 메모리가 허용하는 크기까지 확장 |
| 실수 | `double` | `double` | `float` |

Java의 `int`는 $-2^{31}$부터 $2^{31}-1$까지, `long`은 $-2^{63}$부터 $2^{63}-1$까지 저장합니다. C++의 자료형 크기는 구현에 따라 정해지며, 일반적인 대회 환경의 `int`는 32비트, `long long`은 64비트입니다.

Python 정수는 값이 커지면 저장 공간도 늘어납니다. 큰 정수의 연산 비용은 자릿수의 영향을 받습니다.

### 연산 도중의 오버플로

자료형이 표현할 수 있는 범위를 벗어나면 오버플로가 발생합니다. C++의 부호 있는 정수 오버플로는 동작이 정의되지 않으며, Java의 정수 연산은 정해진 비트 폭에 맞춰 결과가 잘립니다.

C++과 Java에서 두 `int`를 곱한 뒤 넓은 정수 변수에 저장하더라도, 곱셈 자체가 `int`로 수행되면 중간 결과가 먼저 넘칠 수 있습니다. 한쪽 피연산자를 넓은 자료형으로 바꾸고 곱해야 합니다.

| 동작 | C++ | Java | Python |
| --- | --- | --- | --- |
| 넓은 정수로 곱셈 | `1LL * a * b` | `1L * a * b` | `a * b` |
| 실수 나눗셈 | `double(a) / b` | `(double) a / b` | `a / b` |

### 실수와 정밀도

실수 자료형은 값을 유한한 비트로 근사하여 저장합니다. 정수의 개수나 정확한 나머지가 필요한 계산은 정수 연산으로 처리합니다. 실수 답을 요구하는 문제는 문제의 허용 오차와 출력 자릿수를 확인합니다.

### 복잡도

아래 예제의 두 길이와 곱은 크기가 제한된 정수입니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 두 길이의 곱 | $O(1)$ | 추가 $O(1)$ |

## 예제

### 문제

직사각형의 넓이를 구합니다.

### 입력

첫째 줄에 가로와 세로 길이 $A,B$가 공백으로 구분되어 주어집니다. 두 길이는 10000보다 작은 자연수입니다.

### 출력

직사각형의 넓이를 출력합니다.
