## 개념

### 행과 열의 변화량

격자의 위치를 행 $r$과 열 $c$로 나타냅니다. 위쪽으로 이동하면 행이 $1$ 감소하고, 오른쪽으로 이동하면 열이 $1$ 증가합니다.

| 방향 | 행 변화량 | 열 변화량 |
| --- | --- | --- |
| 위 | -1 | 0 |
| 오른쪽 | 0 | 1 |
| 아래 | 1 | 0 |
| 왼쪽 | 0 | -1 |

행 변화량과 열 변화량을 같은 순서의 배열에 저장하면 반복문으로 네 방향을 처리할 수 있습니다. 새 좌표는 현재 좌표에 해당 방향의 변화량을 더한 값입니다.

### 범위와 이동 조건

배열 인덱스가 0부터 시작하는 $R\times C$ 격자에서 새 좌표 $(nr,nc)$는 다음 조건을 만족해야 합니다.

$$0\le nr<R,\qquad 0\le nc<C.$$

새 좌표가 범위 안인지 먼저 확인한 뒤 해당 칸의 값을 읽습니다. 벽이나 방문 표시가 있는 문제에서는 그 조건까지 확인합니다. 대각선도 이동할 수 있으면 $(-1,-1)$, $(-1,1)$, $(1,-1)$, $(1,1)$을 추가합니다.

이웃을 구한 뒤 방문 순서나 최단 거리를 계산하는 과정은 [DFS](/algorithm-notes/notes/algorithms/dfs/)와 [BFS](/algorithm-notes/notes/algorithms/bfs/)에서 다룹니다.

### 복잡도

각 칸에서 네 방향을 확인합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 한 칸의 이웃 확인 | $O(1)$ | 방향 배열 $O(1)$ |
| R × C 격자의 모든 칸 확인 | $O(RC)$ | 이웃 계산용 추가 $O(1)$ |

## 예제

### 문제

격자의 한 칸에서 상하좌우로 한 번 이동하여 도달할 수 있는 칸들을 구합니다.

### 입력

첫째 줄에 행 수 $R$과 열 수 $C$가 주어집니다. $1 \le R,C \le 10$입니다. 둘째 줄에 현재 행 $r$과 열 $c$가 주어집니다. $1 \le r \le R$, $1 \le c \le C$입니다. 모든 값은 공백으로 구분됩니다.

### 출력

격자 안에 있는 이웃의 행과 열을 위, 오른쪽, 아래, 왼쪽 순서로 한 줄씩 출력합니다. 이웃이 없으면 NONE을 출력합니다.
