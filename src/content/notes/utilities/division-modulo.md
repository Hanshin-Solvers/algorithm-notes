## 개념

### 정수 나눗셈

양의 정수끼리 나눌 때 정수 몫은 소수 부분을 버린 값입니다. $7$을 $3$으로 나누면 몫은 $2$, 나머지는 $1$입니다.

음수가 포함되면 언어별 규칙이 달라집니다. C++과 Java의 정수 나눗셈은 $0$ 방향으로 소수 부분을 버립니다. Python의 `//`는 수학적인 내림을 수행합니다.

| 계산 | C++ | Java | Python |
| --- | --- | --- | --- |
| 양수 몫 | `7 / 3` → 2 | `7 / 3` → 2 | `7 // 3` → 2 |
| 음수 몫 | `-7 / 3` → -2 | `-7 / 3` → -2 | `-7 // 3` → -3 |
| 음수 나머지 | `-7 % 3` → -1 | `-7 % 3` → -1 | `-7 % 3` → 2 |

### 내림과 올림

내림은 주어진 값 이하의 가장 큰 정수, 올림은 주어진 값 이상의 가장 작은 정수입니다. 나누는 수 $B$가 양수일 때 내림 몫 $q$와 나머지 $r$을 다음과 같이 정합니다.

$$
A=Bq+r,\qquad 0\le r<B.
$$

$r=0$이면 올림 몫도 $q$이고, $r>0$이면 $q+1$입니다. 예를 들어 $-7/3$의 내림은 $-3$, 올림은 $-2$입니다.

$A\ge0$, $B>0$일 때 올림 몫은 $(A+B-1)/B$의 정수 몫으로도 계산합니다. 덧셈 범위를 줄이려면 몫에 나머지의 존재 여부를 더하는 방식을 사용할 수 있습니다.

### 모듈러 연산

양의 정수 $M$에 대해 값을 $0$부터 $M-1$까지의 나머지로 나타냅니다. C++과 Java에서는 음수 결과를 정규화할 때 `((a % m) + m) % m`, Python에서는 양수 `m`에 대해 `a % m`을 사용합니다.

$$
(a+b)\bmod M=((a\bmod M)+(b\bmod M))\bmod M
$$

곱셈도 각 수의 나머지를 먼저 구해 계산할 수 있습니다. 중간 곱이 자료형 범위를 넘는지는 별도로 확인합니다. 나눗셈은 이 규칙을 그대로 적용할 수 없으며, 나머지 연산에서의 나눗셈에는 역원이 필요합니다.

### 복잡도

예제 범위의 정수 연산을 기준으로 합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 몫·나머지·올림 계산 | $O(1)$ | 추가 $O(1)$ |

## 예제

### 문제

A를 B로 나눈 값의 내림, 올림과 음이 아닌 나머지를 구합니다.

### 입력

첫째 줄에 정수 $A$와 자연수 $B$가 공백으로 구분되어 주어집니다. $-9999 \le A \le 9999$, $1 \le B \le 100$입니다.

### 출력

내림 몫, 올림 몫, 0 이상 B 미만의 나머지를 공백으로 구분하여 출력합니다.
