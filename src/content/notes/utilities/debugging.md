## 개념

### 중간 상태 확인

디버깅 출력은 입력값, 반복 위치, 계산 중간값을 확인할 때 사용합니다. 표준 출력은 문제의 정답에, 표준 오류는 확인용 기록에 사용하면 둘을 구분할 수 있습니다.

| 동작 | C++ | Java | Python |
| --- | --- | --- | --- |
| 표준 오류 출력 | `cerr << x` | `System.err.println(x)` | `print(x, file=sys.stderr)` |
| 조건 확인 | `assert(조건)` | `assert 조건` | `assert 조건` |
| 경과 시간용 시계 | `chrono::steady_clock` | `System.nanoTime()` | `time.perf_counter()` |

C++의 `assert`는 `NDEBUG`가 정의되면 생략됩니다. Java의 `assert`는 실행 시 `-ea` 옵션으로 활성화합니다. Python은 `-O` 옵션으로 실행하면 `assert`를 생략합니다. 입력을 처리하는 필수 연산은 별도의 실행문으로 작성합니다.

### 경과 시간 측정

측정할 작업 직전과 직후에 시각을 읽고 차이를 구합니다. C++의 `steady_clock`과 Java의 `nanoTime`, Python의 `perf_counter`는 경과 시간을 측정할 때 사용합니다.

측정값은 실행마다 달라집니다. 입력 대기와 디버깅 출력을 측정 구간에 넣으면 그 시간도 포함됩니다. 계산 시간만 확인하려면 입력을 먼저 읽고 측정 구간의 계산을 마친 뒤 기록을 출력합니다.

### 제출할 때

확인용 출력은 풀이를 점검할 때 활성화하고 제출할 때 해제합니다. 반복문 안의 많은 출력은 실행 시간을 늘릴 수 있습니다.

### 복잡도

원소 수를 $N$, 추가로 출력하는 문자 수를 $L$이라고 합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 입력 저장 후 합 계산 | $O(N)$ | 입력 $O(N)$ |
| 디버깅 기록 출력 | $O(L)$ | 기록 구성 방식에 따라 결정 |

## 예제

### 문제

주어진 자연수들의 합을 구합니다.

### 입력

첫째 줄에 원소 수 $N$이 주어집니다. $1 \le N \le 100$입니다. 둘째 줄에 10000보다 작은 자연수 $N$개가 공백으로 구분되어 주어집니다.

### 출력

합을 출력합니다.
