## 개념

### 숫자 문자와 정수

문자 `'7'`은 숫자를 나타내는 문자이고 정수 $7$은 계산에 사용하는 값입니다. 영어 숫자 문자는 `'0'`부터 `'9'`까지 연속된 문자 코드에 배치되어 있습니다. 따라서 숫자 문자에서 `'0'`의 코드를 빼면 해당 숫자를 얻습니다.

| 동작 | C++ | Java | Python |
| --- | --- | --- | --- |
| 숫자 문자 → 정수 | `c - '0'` | `c - '0'` | `int(c)` 또는 `ord(c) - ord('0')` |
| 0부터 9 → 숫자 문자 | `char('0' + x)` | `(char) ('0' + x)` | `chr(ord('0') + x)` |
| 십진 문자열 → 정수 | `stoi(s)` | `Integer.parseInt(s)` | `int(s)` |
| 정수 → 문자열 | `to_string(n)` | `String.valueOf(n)` | `str(n)` |

### 문자열 전체를 변환하기

`"204"`를 정수로 변환하면 $204$입니다. 각 문자를 따로 변환하면 $2$, $0$, $4$를 얻습니다. 문자열 앞의 $0$은 정수로 변환한 값에 남지 않습니다. `"0024"`의 정수 값은 $24$입니다.

정수를 문자열로 바꾸면 문자열 결합이나 자릿수 확인에 사용할 수 있습니다. 입력 문자열을 숫자로 바꿀 때는 문자열이 숫자 형식인지와 결과가 자료형 범위 안인지 확인합니다.

### 복잡도

문자열 또는 수의 자릿수를 $L$이라고 합니다. 예제처럼 크기가 제한된 정수 변환을 기준으로 합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 숫자 문자 하나 변환 | $O(1)$ | 추가 $O(1)$ |
| 문자열을 정수로 변환 | $O(L)$ | 추가 $O(1)$ |
| 정수를 문자열로 변환 | $O(L)$ | 결과 $O(L)$ |

## 예제

### 문제

십진 숫자 문자열이 나타내는 값과 각 자릿수의 합을 구합니다.

### 입력

첫째 줄에 숫자 문자로 이루어진 길이 $1$ 이상 $4$ 이하의 문자열이 주어집니다. 문자열이 나타내는 값은 10000보다 작은 자연수입니다. 앞에 0이 붙을 수 있습니다.

### 출력

첫째 줄에 앞의 0을 제거한 정수 값을 출력합니다. 둘째 줄에 각 자릿수의 합을 출력합니다.
