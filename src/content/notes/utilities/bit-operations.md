## 개념

### 정수를 비트로 표현하기

정수의 이진 표현에서 각 자리는 $0$ 또는 $1$입니다. 오른쪽 끝을 0번째 비트라고 하며, $k$번째 비트의 값은 $2^k$입니다. 여러 항목의 선택 여부를 한 정수의 비트들에 저장할 수 있습니다.

| 연산 | 기호 | 의미 |
| --- | --- | --- |
| AND | `&` | 두 비트가 모두 1이면 1 |
| OR | `\|` | 하나 이상 1이면 1 |
| XOR | `^` | 두 비트가 다르면 1 |
| NOT | `~` | 각 비트를 반전 |
| 왼쪽 이동 | `<<` | 비트를 왼쪽으로 이동 |
| 오른쪽 이동 | `>>` | 비트를 오른쪽으로 이동 |

예를 들어 $5=101_2$, $3=011_2$이면 AND는 $1$, OR는 $7$, XOR는 $6$입니다.

### 특정 비트 확인·변경

음이 아닌 정수 `x`의 `k`번째 비트에 다음 연산을 적용합니다.

| 동작 | C++ | Java | Python |
| --- | --- | --- | --- |
| 1인 비트 마스크 | `1 << k` | `1 << k` | `1 << k` |
| 비트 값 확인 | `(x >> k) & 1` | `(x >> k) & 1` | `(x >> k) & 1` |
| 비트를 1로 설정 | `x \| (1 << k)` | `x \| (1 << k)` | `x \| (1 << k)` |
| 비트를 0으로 설정 | `x & ~(1 << k)` | `x & ~(1 << k)` | `x & ~(1 << k)` |
| 비트 반전 | `x ^ (1 << k)` | `x ^ (1 << k)` | `x ^ (1 << k)` |

C++과 Java에서는 이동량과 결과가 사용하는 정수 폭 안에 있도록 정합니다. Python의 `~x`는 `-x-1`이므로 하위 $K$비트만 반전하려면 `x ^ ((1 << K) - 1)`을 사용합니다. 이 식은 원래 값이 $0\le x<2^K$일 때 해당 범위의 비트를 반전합니다.

### 복잡도

예제의 고정된 정수 범위를 기준으로 합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 비트 확인·설정·제거·반전 | $O(1)$ | 추가 $O(1)$ |

## 예제

### 문제

정수 X의 K번째 비트를 확인하고, 해당 비트를 각각 설정·제거·반전한 결과를 구합니다. 각 연산은 원래 X에 적용합니다.

### 입력

첫째 줄에 $X,K$가 공백으로 구분되어 주어집니다. $0 \le X \le 255$, $0 \le K \le 7$입니다. 비트 번호는 오른쪽 끝에서 $0$부터 셉니다.

### 출력

원래 비트 값, 1로 설정한 결과, 0으로 설정한 결과, 반전한 결과를 공백으로 구분하여 출력합니다.
