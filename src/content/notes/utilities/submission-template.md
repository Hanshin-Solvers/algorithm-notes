## 개념

### 프로그램의 시작점

제출 코드는 입력을 읽고, 답을 계산한 뒤, 정해진 형식으로 출력하는 프로그램입니다. 대회에서 지정한 언어 버전을 선택하고 해당 언어의 시작점에 풀이를 작성합니다.

| 항목 | C++ | Java | Python |
| --- | --- | --- | --- |
| 언어 기준 | C++20 | Java 17 | Python 3 |
| 시작점 | `int main()` | `public static void main(String[] args)` | 파일의 첫 실행문 |
| 코드 파일 | `main.cpp` | `Main.java` | `main.py` |
| 표준 입력 | `cin` | `Scanner`, `BufferedReader` | `input`, `sys.stdin` |
| 표준 출력 | `cout` | `System.out` | `print`, `sys.stdout` |

Java의 공개 클래스 이름이 `Main`이면 파일 이름도 `Main.java`로 맞춥니다. C++의 `using namespace std;`는 표준 라이브러리 이름을 `std::` 없이 사용할 수 있게 합니다.

### 입력·계산·출력

입력 조건에서 값의 개수와 순서를 확인합니다. 계산 결과는 출력 형식에 맞춰 내보냅니다. 여러 값을 한 줄에 출력할 때는 공백으로 구분하고, 줄이 끝나는 위치에는 줄바꿈을 넣습니다.

### 복잡도

두 정수를 더하는 예제를 기준으로 합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 두 정수의 합 | $O(1)$ | 추가 $O(1)$ |

## 예제

### 문제

두 양의 정수의 합을 구하여라.

### 입력

첫째 줄에 두 양의 정수 $A,B$가 공백을 사이에 두고 주어진다. $1\le A,B<10\,000$이다.

### 출력

두 수의 합을 출력한다.
