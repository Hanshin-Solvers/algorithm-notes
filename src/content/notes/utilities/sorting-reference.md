## 개념

### 비교 기준

정렬 함수 사용법과 사용자 정의 정렬은 [Sorting](/algorithm-notes/notes/algorithms/sorting/)에서 설명합니다. 점수 내림차순, 동점이면 번호 오름차순인 문제와 세 언어 예제 코드도 해당 문서에서 확인할 수 있습니다.

| 항목 | C++ | Java | Python |
| --- | --- | --- | --- |
| 비교 방식 | 두 원소의 순서를 비교하는 함수 | `Comparator` | 각 원소의 `key` |
| 점수 내림차순·번호 오름차순 | 점수가 다르면 점수 비교, 같으면 번호 비교 | 두 기준을 순서대로 비교 | `key=lambda x: (-x[1], x[0])` |
| 정수 비교 | `<`, `>` | `Integer.compare(a, b)` | 정렬 키의 정수 값 |
| 같은 기준의 원래 순서 유지 | `stable_sort` | 객체 배열·리스트 정렬 | `sort`, `sorted` |

복합 키는 앞 기준이 같을 때 다음 기준을 비교합니다. 비교 조건은 일관되어야 하며, 같은 값끼리의 비교 결과도 각 언어의 정렬 규칙에 맞춰 작성합니다.

### 복잡도

원소 수를 $N$이라고 합니다.

| 연산 | 시간복잡도 | 공간복잡도 |
| --- | --- | --- |
| 표준 비교 정렬 | $O(N\log N)$ | C++ sort 추가 $O(\log N)$, Java 객체 정렬·Python 정렬 추가 $O(N)$ |
